# Original starter library

These starter assets were generated for Brill-AR from geometric shapes, procedural motion, synthesized sine waves and original octahedron geometry, not copied from stock or Artivive. No external artwork, recordings or trademark assets. Generator: tests/make-library.py (Pillow required for regeneration, not runtime).

- star.png, ring.png: transparent geometric PNG overlays.
- pulse.gif: transparent expanding ring, repeating GIF.
- bell.wav: synthesized two-note bell, 1.2s mono PCM, no recorded audio.
- gem.glb: octahedron with purple PBR material.

Available for reuse and editing within the user's artwork. This starter set is small and is not a claim to match Artivive's catalog size or content variety. Bell is silent until the user selects preview/play, subject to normal browser audio rules.

- orbit.mp4/orbit-poster.png: original two-second orbital geometric animation, H264/yuv420p, 256x256, no audio.
