# סטודיו AR

עורך יצירה ראשון לבניית חוויות AR מעל יצירות אמנות, בדפדפן, בלי שרת ובלי התקנה.

## מה יש כאן

- `index.html` + `editor.js` + `style.css` - העורך: מעלים תמונת יצירה, מוסיפים אלמנטים (סרטון, תמונה, צליל), מסדרים בגרירה על תצוגה חיה, ושומרים.
- `play.html` + `player.js` - הנגן: מריץ יצירה שמורה במצלמה (WebAR). פותחים מקישור "תצוגה בטלפון" בעורך.
- `shared.js` - ליבה משותפת: שמירה מקומית (IndexedDB), ייצוא/ייבוא לקובץ JSON, וייצור מטרת-זיהוי מהתמונה שהועלתה.
- `assets/demo/` - יצירת הדמו (נבנה מנכסים שנוצרו עבור הפרויקט).
- `external/` - מנוע ה-AR (קוד פתוח, רישיון MIT של Niantic Spatial - ראו `8THWALL-MIT-LICENSE.txt`). לא לערוך ידנית; לנעול גרסה עובדת.

## עקרונות

- הכל רץ מקומית בדפדפן: קבצים שהמשתמשית מעלה נשמרים ב-IndexedDB של המכשיר בלבד, ולא נשלחים לשום שרת.
- מצלמה בלבד, בלי מיקרופון.
- הקלטת 10 שניות מתוך החוויה, עם שיתוף/שמירה לגלריה דרך גיליון השיתוף של iOS.

## הרצה

אתר סטטי לגמרי - מעלים את התיקייה לכל אירוח סטטי (למשל surge.sh) ופותחים את `index.html`. אין שלב בנייה.
