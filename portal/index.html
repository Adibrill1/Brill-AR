יצירה חדשה / New trigger image

תמונת טריגר היא כל תמונה מודפסת שהמערכת מזהה — קלף, מדבקה, פוסטר או הדפס. המבקרים יכוונו אליה את המצלמה כדי לפתוח את חוויית ה-AR שלך.

גררו את הפינות כדי לחתוך, או את המרכז כדי להזיז

הספרייה המשותפת — תרומת אלמנטים / Shared library

העלו אלמנטים תלת-מימדיים (GLB) או מדבקות ואיורים (PNG/JPG/WebP) לשיתוף כלל היוצרים. כל תרומה עוברת אישור לפני שהיא מצטרפת לספרייה שכולם רואים.
